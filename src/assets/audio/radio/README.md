# Radio

Una única carpeta para todo el módulo: **todo lo que hay aquí suena en RADIO
YERMO** (96.2), la única emisora con programación. ONDA REFUGIO (104) se queda
sin música a propósito.

Arrastra un mp3 a esta carpeta y aparece solo en la lista de pistas, sin tocar
código. La convención de nombre es `Título - Artista` (por ejemplo
`Big Iron - Marty Robbins.mp3`); si no lleva guion, el nombre entero se usa como
título.
